# v1.5 — Upstream Claude Code Features

Baseline: v1.4.0. SDK: `@anthropic-ai/claude-agent-sdk ^0.2.112`.

Items ordered by recommended implementation sequence.

---

## 1. Effort selector + toolbar responsive redesign

Expose the SDK `effort` option, and redesign the model/mode/effort toolbar to be mobile-friendly.

### Effort values
- `1=low` `2=medium` `3=high` `4=xhigh` `5=max`
- Default: `3` (high)
- `4` / `5` (xhigh/max) only valid on Opus — if user switches model to Sonnet/Haiku while effort > 3, auto-clamp to `3`; if effort ≤ 3, leave it alone

### Desktop / tablet layout
- Flat inline buttons, same style as current model (H S O) and mode tabs
- Effort buttons: `1` `2` `3` `4` `5`
- All three groups (model / mode / effort) sit in toolbar-right, stacked or inline as space allows

### Mobile layout (new pattern — applies to model, mode, AND effort)
- Each group collapses to a **single button** showing the current selection (e.g. `S`, `bypass`, `3`)
- Tapping the button opens a **vertical inline selector** (expands in-place above the button, not a modal)
- After picking an option the selector closes and the single button updates to reflect the choice
- This same pattern replaces the current flat-button layout for model and mode on mobile

**Files to touch:** `src/views/ChatView.vue` (toolbar-right, model/mode selectors), possibly extract a `ToolbarPicker.vue` reusable component

**Status:** done

## 2. Auto mode preset

Bundle `bypassPermissions` + `enableFileCheckpointing` into a single toggle.
Upstream "auto mode" = skip permission prompts + keep a file safety net.

- New permission-mode option: `auto`
- Visual: distinct color (purple) on input border
- Server maps `auto` → `{ permissionMode: 'bypassPermissions', enableFileCheckpointing: true }`

**Status:** not started

---

## 3. File checkpoint rewind

Surface the SDK's built-in file undo. Enabled automatically when `auto` mode is on.

- `enableFileCheckpointing: true` snapshots files before each edit
- `Query.rewindFiles(toMessageId)` restores files to state before that message
- UI: "↶ undo edit" button on `Edit`/`Write` tool result messages
- Only available while session is active (query handle is in-memory)

**Status:** not started

---

## 4. Session branching

Fork a session from any turn and explore a different path, non-destructively.

- SDK: `forkSession(sessionId, { upToMessageId, title })` (native API)
- Also uses: `resumeSessionAt: messageUuid` + `forkSession: true` query options
- UI: "branch from here" button on user turn messages
- After fork: navigate to new session, show "branched from …" badge in breadcrumb
- Parent session is preserved untouched

**Status:** not started — replaces design in `FEATURE_session-rewind.md`

---

## 5. BTW — interjection while Claude is running

Let users inject a side note mid-stream without cancelling the current task.

- Requires refactoring `prompt.js` to **streaming input mode** (async iterable)
- `Query.interrupt()` + push new user message into the active input stream
- UI: small "btw…" text input appears below chat while `isRunning === true`
- Injected message shows with a "btw" badge in the transcript

**Status:** not started — largest item (streaming-input refactor of `prompt.js`)
